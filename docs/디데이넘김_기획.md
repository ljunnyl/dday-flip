# 디데이 넘김 기획

## 현재 상태 (2026-10-24)

- 방향 확정: 갤럭시 / 가족용 / PC에서 먼저 확인.
- 다음 할 일:
  - 시험 샘플 구성: 달력 사진 10~15장 + 달력 없는 일상 사진 10~15장 혼합 폴더(`photos/`) 마련.
  - 숫자 인식 및 달력 유무 선별 스크립트 작성 및 통과 기준 검증.
  - 전체 140여 장 대상 파이프라인 수행 및 영상 1편 완성.
- 남은 결정: 사진 가져오는 경로(폰 직접 연결 / 구글 포토 / 삼성 클라우드), 아이와 함께 찍은 구도인지(얼굴 위치 맞춤 필요 여부).

## 1. 왜 만드나

매일 D-day 달력과 아이 사진을 기본 카메라로 찍어 왔다(D+10~D+150 무렵). 이걸 넘김 영상으로 만들고 싶은데, 수천 장 갤러리에서 하루 한 장씩 골라 모으는 일이 막막하다.

## 2. 기존 앱 대비 딱 하나의 개선

매일 사진 → 성장 영상 앱은 이미 있지만, 대개 처음부터 그 앱 안에서 찍어야 한다. 앱을 늦게 알게 된 부모는 지난 사진을 손으로 골라 넣어야 한다.

> 앱을 늦게 깔아도, 갤러리에 흩어진 매일 사진을 알아서 찾아 줄 세워 영상으로 만들어 준다.

신뢰 포인트: 사진은 기기 밖으로 나가지 않는다.

## 3. 첫 버전 범위

넣는 것:
1. 생일 입력 + 사진 폴더 지정 → 달력 사진 자동 선별, 날짜별 한 장씩 정렬
2. 빠진 날·애매한 날만 사람에게 확인 요청
3. 넘김 속도·"D+N" 자막 선택 → 영상 저장

미루는 것(2차): 얼굴 위치 맞춤, 배경음악, 앞으로 찍을 때 구도 가이드, 폰 앱.

## 4. 핵심 가정 및 사전 검증 방법

| 전제 (가정) | 설명 | 확인 방법 |
|---|---|---|
| 매일 촬영 여부 | D+10~D+150 기간 동안 실제로 누락 없이 매일 사진을 찍었는가? | 사진 파일들의 EXIF 촬영일 분포를 날짜별로 집계하여 연속성 및 결측 구간 확인 |
| 달력 넘김 누락 여부 | 달력 숫자를 전날에서 넘기지 않고 그대로 촬영한 날이 있는가? | OCR로 인식한 D-day 연속 시퀀스에서 동일 숫자 중복 출현 구간 감지 |
| EXIF 시각 보존 여부 | 사진 원본의 EXIF 메타데이터(`DateTimeOriginal`)가 훼손 없이 유지되어 있는가? | 샘플 및 전체 파일의 EXIF 태그 파싱 성공률 및 결측 여부 스크립트 검사 |
| 판독 가능성 | 원거리 촬영, 기울어짐, 조명/그림자, 아기 움직임 속에서도 달력 숫자가 읽히는가? | 다양한 구도/거리의 샘플 사진으로 전처리(회전·대비) 및 OCR 판독률 테스트 |

## 5. 예외 처리 규칙

| 예외 상황 | 감지 기준 | 1단계 처리 규칙 | 상태 |
|---|---|---|---|
| 달력 숫자 vs EXIF 계산 괴리 | 달력 OCR 숫자와 EXIF(촬영일 - 생일) 일수가 불일치 | 확인 목록에 기록 후 사용자 확인. 기본 영상 표기는 달력 숫자 우선 | 확정 |
| 달력 미넘김 (같은 숫자 연속) | 서로 다른 날짜의 사진에서 동일한 달력 숫자가 연속 검출 | 전날 미넘김 의심 건으로 분류, 확인 목록에 플래그 표시 (영상 포함 방식은 미정) | 미정 (둘 다 유지 vs 2일차 자동 보정 vs 사람 선택) |
| 결측일 (빠진 날) | 특정 일수(D+N)에 해당하는 사진이 존재하지 않음 | 결측 구간 건너뛰고 다음 날로 연결 (안내 화면/프레임 유지 여부는 미정) | 미정 (건너뛰기 vs 직전 프레임 유지 vs 빈 화면 안내) |
| OCR 오인식 (문자 왜곡/범위 이상) | 인식 숫자가 `[EXIF 일수 ± 2]` 범위를 벗어나거나, 시퀀스 역전, 유사 문자(O/0, I/1 등) 혼동 | 유사 문자 교정 룰 적용 후 유효 범위 초과 시 '인식 실패' 처리 및 EXIF 추정값으로 대체 제안 | 확정 |
| 자정 넘겨 촬영 (심야/새벽) | 00:00~04:00 시간대 촬영 사진 | 달력 숫자 및 직전 날짜 시퀀스와 대조하여 전날 날짜 귀속 여부 판별 (기본 규칙 미정) | 미정 (새벽 04시 이전 전날 귀속 vs 당일 귀속) |
| 1단계 PC 수동 검수 방식 | 애매한 사진 및 예외 케이스를 사람이 확인하고 보정하는 방식 | 터미널 CLI 리포트 및 이상치 목록 CSV/텍스트 리포트 생성 (별도 GUI는 제외) | 확정 |

## 6. 1단계 검증 통과 기준 (Success Metrics)

1단계 PC 프로토타입의 검증 통과는 아래 3가지 지표를 충족할 때 완료로 본다:

1. **숫자 인식 성공률**: 
   - 달력이 포함된 사진 중 **90% 이상** D-day 숫자를 정확하게 자동 판독 (오차 없음).
2. **선별(달력 유무 판별) 오분류율**: 
   - 정밀도(Precision): 달력 사진으로 분류한 것 중 달력이 없는 사진 비율 **5% 이하**.
   - 재현율(Recall): 실제 달력 사진인데 놓치고 제외한 비율 **5% 이하**.
3. **수동 확인(개입) 허용 비율**:
   - 전체 사진 중 사람의 수동 개입(확인/수정/선택)이 필요한 사진 비율 **10% 이하** (140여 장 기준 14장 이내).
