# 처리 흐름과 날짜의 의미

## 날짜 세 종류

| 이름 | 출처 | 의미 | 주의 |
|---|---|---|---|
| 찍은 날 | 사진 파일 안의 촬영 정보(EXIF) | 카메라가 기록한 촬영 시각 | 메신저로 받은 사진·편집본은 비어 있거나 저장 시각일 수 있다. 파일 수정 시각으로 대신하지 않는다 |
| 달력 숫자 | 사진 속 D-day 달력 글자 인식 | 그 사진이 "며칠째" 사진인지 — 정렬 기준의 1순위 | 인식 실패·오인식 가능. 찍은 날 계산값과 다르면 사람 확인 대상 |
| 생일 기준 일수 | 찍은 날 − 생일 (Git 밖 설정) | 달력 숫자를 못 읽을 때의 대체값 | 생일 당일을 D+0으로 볼지 D+1로 볼지 달력 표기와 맞춰 확정 필요 |

## 단계

1. 입력: `photos/` 아래 사진 전부(읽기만 함)
2. 선별: 달력이 찍힌 사진만 고름
3. 일수 결정: 달력 숫자 → 없으면 생일 기준 일수. 둘이 어긋나면 확인 목록에 넣음
4. 하루 한 장: 같은 일수가 여러 장이면 가장 선명한 것
5. 출력: `output/`에 확인 목록과 영상
